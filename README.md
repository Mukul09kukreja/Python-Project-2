🚀 ASCII Greeting Generator (Cowsay Project)

A fun Python CLI project that generates an ASCII art greeting using user input.

📌 Overview

This project uses the cowsay library to display a greeting message with an ASCII character in the terminal.

It demonstrates:

Command-line argument handling (sys.argv)

Use of external Python libraries

Simple CLI-based interaction

⚙️ Features

🗣️ Accepts user input from terminal

🐄 Displays ASCII art (Trex)

⚡ Fast and simple execution

💡 Beginner-friendly project

🛠️ Tech Stack

Language: Python

Library: cowsay
